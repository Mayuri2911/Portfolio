📌 Short Summary
A personal portfolio website showcasing my skills, projects, and experience as a .NET Backend Developer. Built to present real-world project work, technical expertise, and provide an easy way for recruiters to connect with me.

🧑‍💻 About the Project
This portfolio website highlights my professional journey, technical skills, and hands-on experience in developing scalable and secure web applications. It includes dedicated sections for About Me, Skills, Projects, Services, and Contact, offering a clear and structured overview of my profile.
The project focuses on clean UI design, responsiveness, and simplicity while effectively representing my backend development expertise and problem-solving approach.

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend Knowledge Showcased: C#, ASP.NET, ASP.NET Core Web API
Database: SQL Server
Tools: Git, GitHub, VS Code / Visual Studio
Deployment Ready: Can be hosted on GitHub Pages / Azure / IIS

✨ Features
Responsive and clean UI design
About Me & Skills overview
Project showcase section
Services offered
Contact form with user interaction
Social media and GitHub links

📂 Project Structure
/index.html – Main landing page
/css – Styling files
/js – JavaScript functionality
/images – Portfolio images and icons

🚀 How to Run Locally
Clone the repository
git clone https://github.com/Mayuri2911/Portfolio.git
Open index.html in your browser
Customize content as needed

🎯 Purpose

This portfolio is created to:
Showcase my technical skills and projects
Build a strong professional presence
Help recruiters understand my experience quickly
